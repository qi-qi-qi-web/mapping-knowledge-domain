# 研究资料说明

本目录保存原始研究报告与图，作为项目的**设计输入**，不是经过逐条核验的数据源目录。

## 使用限制

- 报告中的 arXiv、数据集、模型指标等引用**未逐条核验**；不得直接把报告中的数字、链接、数据集规模当作本项目的事实或已核验来源。
- 项目实际使用的来源以 [`data/registry/sources.json`](../../data/registry/sources.json) 为准；只有 `status=verified` 且 `used_in` 含当前阶段的来源可被事实引用。
- 需要引用报告中的某个来源时，请回到原始指南/登记页核验，并在 `sources.json` 留痕。

## 文件

- `大规模急诊全流程会诊知识图谱研究报告.md`：原文，未改动。
- `figures/`：报告引用的 8 张图，保持原文件名。
